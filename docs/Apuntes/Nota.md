
# Primero revisamos el avance de codigo
Antes del nuevo concepto, cada grupo mostrara que parte del flujo implemento, como funciona y que cambio pequeño puede hacer sin rehacer todo.

1. La persona puede completar el flujo principal?
2. pueden ubicar donde harian una modificacion?
3. el grupo entiende que hace cada parte del codigo?
4. que pantalla o paso falta para completar la tarea?

## Regla de la revision
No buscamos diseño todavia, buscamos evidencia de avance, compresion y capacidad de cambio
