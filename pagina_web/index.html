El desafío en el taller

El caos de stock que frena
a tu equipo todos los días

En un taller con varios técnicos, el inventario sin sincronización digital genera fricciones costosas y pérdidas invisibles.

Reservas duplicadas

Dos técnicos intentan usar la misma pantalla para clientes distintos al mismo tiempo. Sin un sistema que bloquee atómicamente el stock, los conflictos son inevitables.

VaultTecno resuelve: Reserva atómica en BD — solo uno gana

Repuestos que salen de estantería sin saber en qué equipo o para qué cliente se instalaron. La factura no cierra y los datos de calidad se pierden.

Arquitectura y stack

Decisiones técnicas del proyecto

Detalles de ingeniería, seguridad y patrones de desarrollo aplicados en VaultTecno.

Arquitectura por características (features). Navegación declarativa con go_router y rutas protegidas por rol. Gestión de estado con Provider / ChangeNotifier para reactividad limpia y sin dependencias pesadas.

BD relacional PostgreSQL con APIs REST inmediatas vía Supabase. Row Level Security (RLS) aplicado a nivel de servidor para que un técnico nunca pueda leer o modificar reservas ajenas sin rol de admin. Autenticación con tokens JWT vía Supabase Auth.

La reserva ejecuta un UPDATE repuesto SET estado = 'reservado' WHERE id = $1 AND estado = 'disponible'. Si otro técnico ya lo tomó en el mismo milisegundo, el rowCount devuelve 0 y la app notifica el conflicto y refresca el catálogo automáticamente. El modo es online-only para que nunca haya datos obsoletos en caché local.

VaultTecno es una herramienta interna de taller: el encargado es quien conoce a su equipo y decide quién tiene acceso. Un registro público abierto crearía usuarios no verificados con acceso a datos sensibles del negocio. El flujo de onboarding correcto es: encargado crea cuenta → técnico inicia sesión.

La app implementa manejo de errores en red, estados de carga con skeleton shimmer, validaciones de formulario, anti-double-submit en botones de confirmación (se deshabilitan durante la petición) y respuestas hápticas. El prototipo Figma es una maqueta de flujo sin lógica de error ni estados de borde.
